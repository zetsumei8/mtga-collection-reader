# Launch kit

## One-line description

Free, standalone Windows export of the cards you own in MTG Arena—CSV and JSON for theorycrafting without a subscription.

## 30-second demo script

1. Start with Arena open at the Home screen.
2. Open **MTGA Collection Reader** and show the **Get My MTGA Collection** button.
3. Click it, briefly show the progress/complete state, then click **Open exports**.
4. Show `mtga_collection.csv` and `mtga_collection.json` in the export folder.
5. End on this text: **Your Arena collection. Your tools. No subscription.**

Do not show account names, tokens, the `collection.db` file, or full collection contents in the recording.

## Reddit post

**Title:** Free MTG Arena collection export tool — CSV/JSON for theorycrafting, no subscription

I made a free Windows tool that exports the cards you own in MTG Arena to CSV and JSON.

It is deliberately not a deck builder: the point is to give you a portable collection file so you can theorycraft in whatever tool, spreadsheet, or site you prefer. It uses a temporary read-only helper while Arena is open, retains snapshots locally, and has a manual JSON fallback.

GitHub and download: https://github.com/zetsumei8/mtga-collection-reader

I’d genuinely appreciate feedback on Windows/Arena-version compatibility and export formats people find useful. Please do not post account details, collection files, or API tokens in issues.
